# Building a Reading Habit

Reading every day gives learners repeated contact with real sentence patterns. A short paragraph is often enough if the learner reads it carefully.

## Practice Notes

- Choose a text that is clear and useful.
- Translate one passage at a time.
- Review new words after finishing the exercise.

Code blocks should stay unchanged:

```js
const message = "Do not translate code blocks.";
console.log(message);
```

Useful links, such as [OpenAI](https://openai.com), should keep their original URL while the visible text can be handled normally.
